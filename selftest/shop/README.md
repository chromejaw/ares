# Corner Shop

A small order service. Customers place orders, pay, and can cancel for a refund. Staff look after accounts.

Rules of the shop:
- A customer sees only their own orders.
- Only admins can delete an account.
- An order is refunded once at most, and never for more than was paid.
- Paying in instalments never costs more or less than the order total.
- An expired coupon gives no discount.
- Receipts are files in the receipts folder; nothing outside it is ever served.
- If checkout says it failed, the customer was not charged.
