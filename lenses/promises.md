# Shape: what it says against what it does

Somewhere, in words, the system promises a behaviour: a comment stating a rule, a label or message shown to a user, a setting someone can turn on, a limit or contract in the docs, a number advertised to people. The shape is a promise the server doesn't keep: kept on the obvious path only, kept only in the browser, contradicted, or stored and displayed but never read by the logic.

Collect the promises first, then find where each is enforced. For one that looks absent, say where you searched. If the code is right and the words are wrong, say that and mark it low.
