# Shape: a wrong behaviour hiding behind a passing test

A weak test isn't a finding; it is a pointer to one. The shape: a rule that decides access, money, ranking or what is sent to people, whose test would still pass if the rule were deleted, or checks a name the code doesn't use, or only ever sees kind data, or runs on a stand-in more forgiving than the real service, or doesn't exist.

For each such rule, work the realistic awkward case by hand through the code. Report only when the code behaves wrongly, and give the weak or missing test as the reason it went unnoticed.
